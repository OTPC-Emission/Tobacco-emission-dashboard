# Tobacco Emission Monitoring Dashboard v2

## ตรวจสอบไฟล์ล่าสุด
- Cigarette: 46 รายการ (95.8%)
- Cigar: 2 รายการ (4.2%)
- รวม: 48 รายการ

Dashboard เวอร์ชันนี้จึงตั้งค่าเริ่มต้น Product Type เป็น **Cigarette**

## การแก้ไข
1. แก้ logic ที่อาจอ่านคำว่า `Cigarette` ผิดเป็น `Cigar`
2. รองรับคำสะกด Cigarette/Cigarettes/Ciggarette/Ciggarettes
3. กราฟ Trend หลักเปิดมาที่ Cigarette อัตโนมัติ
4. Cigar ยังคงเลือกดูแยกได้จาก Filter
5. ใช้ไฟล์ Excel ล่าสุดเป็น `data/latest.xlsx`

## เกณฑ์
- Tar ≤ 10 mg/มวน
- Nicotine ≤ 1 mg/มวน
- CO ≤ 10 mg/มวน

## ฟังก์ชันรายงาน (v4)
- ปุ่ม **พิมพ์ / บันทึกเป็น PDF**
  - ใช้ตัวกรองปีและประเภทผลิตภัณฑ์ปัจจุบัน
  - เปิดหน้าต่าง Print ของ Browser
  - เลือก Printer เพื่อพิมพ์ หรือเลือก **Save as PDF** เพื่อบันทึกเป็น PDF
  - ระบบซ่อนตัวกรอง ปุ่ม และองค์ประกอบที่ไม่จำเป็นในโหมดพิมพ์อัตโนมัติ

- ปุ่ม **ดาวน์โหลดรายงาน CSV**
  - ดาวน์โหลด KPI และสถิติของปีล่าสุดภายใต้ตัวกรอง
  - รวม Median, Mean, Min, Max, N, % ของเกณฑ์ และ % เปลี่ยนแปลงจากปีก่อน
  - แนบข้อมูลรายการที่ใช้สร้างรายงาน โดยใช้รหัสนิรนามเท่านั้น

# Tobacco Emission Dashboard v7

เวอร์ชันปรับหน้าตาให้ทันสมัยและอ่านง่ายขึ้นสำหรับประชาชน

## สิ่งที่ปรับใหม่
- ปรับสีกราฟเป็น 3 ระดับ
  - น้ำเงิน = ต่ำกว่า 80% ของค่ามาตรฐาน
  - ส้ม = ใกล้ค่ามาตรฐาน (80–100%)
  - แดง = สูงกว่าค่ามาตรฐาน (>100%)
- ปรับหน้าเว็บให้ทันสมัยขึ้น
- เพิ่มส่วนอธิบายการอ่านกราฟ
- เน้นเส้นค่ามาตรฐานตามกฎหมายชัดเจน
- คงการอ่านข้อมูลจาก `data/latest.xlsx`

## การ Deploy
อัปไฟล์ต่อไปนี้ขึ้น GitHub repository:
- index.html
- .nojekyll
- data/latest.xlsx
